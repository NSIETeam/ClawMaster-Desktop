# Agent Note: 在安卓上运行 ClawMaster 桌面版 DSH 产品

Status: proposed

[English](2026-09-18-clawmaster-android-dsh-host.md) | 中文

## 问题

当前安卓应用运行独立的 Java 智能体，并使用自己的聊天、笔记、文件、任务和设置界面。ClawMaster 桌面版运行 DSH Web 客户端，包含固定版本的社区插件和 ClawMaster 产品组合包。仅复用应用图标并不能让安卓应用成为同一产品，Node 进程冒烟测试也不能证明 DSH 功能对齐。

## 提案

在安卓设备上运行同一套 DSH Web 客户端与 ClawMaster 桌面默认 profile。启动 Activity 在 Android WebView 中承载共享 Web 前端；由安卓运行时监督器启动设备本机 Node 进程，等待通过认证的回环地址，再加载该地址，并且不得将其中的 token 写入日志或持久化偏好设置。DSH 主目录与已安装运行时版本保存在应用私有存储中。APK 携带已验证的桌面 harness 和为每个安卓 ABI 构建的 Node 运行时；如需安装其它依赖，只能使用固定的桌面锁文件，并记录来源。

使用桌面 profile 中完全相同的默认组合包顺序和插件版本。启用这些安卓组合包前，先逐一解决平台专属依赖。为具有移动端等价能力的功能实现安卓提供方，并保留原有审批和数据规则。桌面专属能力在安卓实现通过验收前都视为未完成；profile 不得静默移除它，也不得在底层操作无法运行时仍报告该功能可用。

保留 ClawMaster SVG 作为启动器和产品内图标的唯一来源。仅为回环 Web 服务开放范围严格受限的明文通信；除明确交给安卓原生文件选择或外部应用的操作外，拒绝离开本地 DSH 来源的导航；WebView 内存保存本机宿主的认证状态。安卓运行时监督器负责启动、就绪、停止和重启进程；Activity 重建不得启动重复宿主。

只在 GitHub Actions 中构建和验证该移植。托管作业构建桌面 DSH 载荷和安卓 Node ABI，组装但不发布验证 APK，并在 GitHub 云安卓模拟器中测试。覆盖 Android 8/API 26 与 Android 16/API 36，以及两种支持的 ABI、冷启动、Activity 重建、宿主停止与重启、WebView 认证和真实 ClawMaster 工作流。截图和 DOM 断言须确认运行的是共享桌面前端；Node 版本输出或 Activity 成功启动都不足以证明对齐。

## 曾考虑的替代方案

**保留独立 Java 智能体并仿照桌面重做屏幕。** 这样无需将 DSH 及其 profile 移植到安卓，但会长期维护两个在设置、会话、工具和后续行为上不同的应用，无法满足所要求的产品对齐。

**让安卓连接服务器或电脑上的 DSH 宿主。** 远程宿主可避免安卓 Node 和原生适配工作，但用户已选择让 DSH 在安卓设备本机运行。这也会改变工作区数据和凭据的存放位置。

**基于 DSH API 再做一套原生 UI。** 这种做法可以使用安卓控件和系统 API，但仍会重复实现桌面客户端的导航和功能呈现；应承载共享 Web 前端作为产品 UI。

## 验收标准

- 已安装的安卓应用使用同一 SVG 生成的 ClawMaster 图标，并呈现相同的 DSH Web 客户端、导航、产品品牌与桌面默认 profile。
- 安卓 Node 从已安装 APK 在每个受支持 ABI 上启动，并在本机私有 DSH 主目录中运行 `dsh web`。冷启动、应用切后台、Activity 重建、停止和重新启动均不泄露认证 URL，也不创建重复宿主。
- 默认 profile 中桌面用户可访问的每项功能都有明确处置。安卓等价操作在设备上遵循相同审批和数据保护规则；不可用的原生操作不得伪装成可成功调用的能力。
- 云模拟器测试在 API 26 和 API 36 上覆盖模型配置、聊天与会话持久化、工具批准与拒绝、文件选择和编辑、产品组合包、安卓专属权限及重启恢复。
- 测试 APK 使用安卓发布密钥签名，并在获准上传服务器前核对包版本和 ABI 内容，验证 SHA-256 与签名证书。CI 验证 APK 不得用于分发。

## 风险

Node 的安卓移植仍属实验性质。桌面 harness 可能包含不支持安卓的原生包或平台假设，包括终端和电脑控制集成。这些能力须实现安卓专属版本并通过云端测试，之后才可视为可用。安卓前台服务规则、WebView 明文策略、文件选择回调、无障碍权限和后台进程限制也可能改变生命周期与首次启动体验。APK 会明显大于现有独立应用；首次依赖准备不能阻塞界面，也不能绕过锁文件、哈希或审批检查。
